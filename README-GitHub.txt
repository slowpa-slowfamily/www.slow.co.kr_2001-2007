Slowfamily GitHub Pages copy

This copy contains the static homepage files with HTML/CSS text converted to UTF-8. The original offline archive is unchanged.

Deployment:
1. Extract these files into the root of a GitHub repository. Do not upload this ZIP as one file.
2. Enable GitHub Pages for the repository from the root of the main branch (or use the GitHub Pages deployment workflow).
3. Open index.html. The original index.htm is also retained.

The .nojekyll marker asks GitHub Pages to serve the static files without Jekyll processing. Internal links and media paths remain relative.

Privacy note: the family diary and photos will be publicly readable if you use a public repository/site.
